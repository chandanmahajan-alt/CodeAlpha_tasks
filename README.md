# CodeAlpha Calculator

A simple console-based basic calculator written in C that performs addition, subtraction, multiplication, and division on two floating-point numbers.

## Features
- Add, subtract, multiply, and divide two numbers
- Input validation for numeric input and menu selection
- Division-by-zero check with a clear error message
- Repeats until the user chooses to exit

## Requirements
- A C compiler (GCC, Clang, or any ISO C99-compatible compiler)
- Tested on Unix-like systems (Linux, macOS). Should compile on Windows with a suitable compiler.

## Files
- `CodeAlpha_Calculator.c` — the calculator program source file
