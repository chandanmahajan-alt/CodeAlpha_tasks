| Task No. | Task Name | Source File | Description |

| **Task 1** | **Calculator Program** | [`CodeAlpha_Calculator.c`](./CodeAlpha_Calculator.c) | Performs basic arithmetic operations using `switch` statements. |
| **Task 2** | **Matrix Operations** | [`CodeAlpha_Matrix.c`](./CodeAlpha_Matrix.c) | Implements Matrix Addition, Multiplication, and Transpose using functions and 2D arrays. |
